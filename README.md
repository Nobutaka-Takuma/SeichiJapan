# 聖地日本 — みんなで作る、小説とアニメの地図帳

小説やアニメに出てくる場所が、現実のどこなのか。
その **「本文 → 場所」の対応づけ（＝解釈）** を、根拠つきで持ち寄って地図にする Web サービスです。

百科事典が共同編集するのは「知識」ですが、ここで共同編集するのは
**物語と現実世界の対応関係**です。文学研究と百科事典の中間のようなものを目指しています。

```
『こころ』 / 夏目漱石

  私が先生と知り合になったのは鎌倉である。   ← 記述（passage）

  由比ヶ浜   ████████████████░░░░  82%        ← 比定（identification）＋確度
  材木座海岸 ███░░░░░░░░░░░░░░░░░  18%

  議論：
   古地図倶楽部「この『海岸』、たぶん由比ヶ浜では。ただ人の多さの描写と…」
   鎌倉在住   「いや、由比ヶ浜でいい。当時の海水浴場は砂浜のごく一部に…」
   文芸助手   「同時代の鎌倉案内では、設備があるのは由比ヶ浜側だけです」
```

## 中心にある考え方

**議論の対象は「場所」ではなく「記述」です。**
本文の一節（または映像作品の場面）をひとつの単位とし、そこに複数の比定案がぶら下がります。
案は消し合いません。対立したまま並び、票の比率が確度として表示されます。

**根拠のない候補は投稿できません。**
比定案には必ず「なぜそこだと考えるか」を書きます。結論だけでなく、
そこに至る推論が残ることに価値があるためです。

## 確度の算出

`src/lib/confidence.ts`

```
重み w = max(0, 賛成票 − 反対票) + 0.5
確度   = w ÷ Σw（同じ記述にぶら下がる全案の合計）
```

- 末尾の `+0.5` はラプラス平滑化の擬似カウント。数票で確度が振り切れるのを防ぎます。
- **案がひとつしかない場合は、票が集まるまで確度が頭打ち**になります（上限 60% から漸増）。
  「まだ誰も検証していない」ことと「検証されて支持された」ことを区別するためです。
- 確度から議論の状態（ほぼ確定／有力説あり／議論中／検証待ち）を判定して併記します。

## 主な画面

| パス | 内容 |
| --- | --- |
| `/` | 全国地図、説が割れている記述、最近の更新 |
| `/works` `/works/[slug]` | 作品一覧／作品の舞台地図と記述一覧 |
| `/passages/[id]` | **記述の議論ページ**。候補ランキング、投票、根拠、コメント |
| `/places` `/places/[id]` | 場所一覧／**逆引き**（この場所に重なる作品） |
| `/map` | 全作品の地図。種別・作品での絞り込み、都道府県別一覧 |
| `/users/[handle]` | 出した説・投じた票・書き込み |
| `/about` | 確度の考え方と参加方法 |

対立する説は地図から消えず、点線の小さいピンとして残ります。
その 2 点間の距離が、そのまま解釈の隔たりとして見えます。

## 技術構成

- **Next.js 15（App Router）/ React 19 / TypeScript** — 更新は Server Actions
- **SQLite（better-sqlite3）** — `data/seichi.db` に自動生成・自動シード
- **Leaflet + OpenStreetMap** — API キー不要。地図タイルは紙色に寄せて表示
- **Tailwind CSS v4**
- 認証は scrypt によるパスワードハッシュ＋DB セッション（Cookie）

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
```

初回起動時に `data/seichi.db` が作られ、サンプルデータが投入されます。
作り直したいときは `rm -rf data` してから再起動してください。

```bash
npm run build && npm start   # 本番ビルド
```

## データモデル

```
works（作品）
  └ passages（記述）        本文引用 kind='text' / 場面の記述 kind='scene'
       ├ identifications（比定案）→ places（実在の場所）
       │    └ votes（賛成・反対）      … ここから確度が出る
       └ comments（議論）              … 案を指定した返信も可
```

## 収録データについてのおことわり

- **初期データはサンプルです。** 座標・比定・確度のいずれも正確性を保証しません。
  それを利用者の手で直していくこと自体がこのサービスの目的です。
- 本文の逐語引用は**保護期間の終わった作品**（夏目漱石・川端康成）に限っています。
  著作権の生きている作品は「場面の記述」として要約で登録しています。
- 地図データは OpenStreetMap を利用しています（タイル取得に外部ネットワークが必要）。
- 実在の場所には、そこで暮らし働いている人がいます。私有地や住宅の特定・公開は行わない前提です。

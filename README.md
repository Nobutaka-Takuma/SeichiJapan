# 聖地日本 — みんなで作る、小説とアニメの地図帳

小説やアニメに出てくる場所を地図の上に集め、その場所についての知識を
**Wikipediaのように誰でも書き足せる** 地図帳です。

どこがどのシーンの場所かは、たいていファンの間ではもう分かっています。
足りないのは、それが一箇所にまとまっていないこと。だからこのサービスの中心は
**場所ごとの項目**であり、議論ではありません。

```
由比ヶ浜                                    ♥ 35   [編集] [履歴]
神奈川県 鎌倉市由比ガ浜
登場する作品 1 ・ シーン 1 ・ 編集 2回/2人      最終更新 古地図倶楽部

  ■ 明治期の海水浴場
  明治中期以降、鎌倉は東京からの避暑地として整備が進み……

  行き方・訪問時の注意
  江ノ島電鉄「由比ヶ浜駅」から徒歩5分。夏季は大変混雑します。

  ここが登場する作品・シーン
  ┌────────────────────────┐
  │ [シーンの画像]              │
  │ 小説『こころ』夏目漱石       │
  │ 「私が先生と知り合になった   │
  │  のは鎌倉である。」          │
  └────────────────────────┘
```

## できること

| | |
| --- | --- |
| **場所の項目を共同編集** | 名前・座標・解説・行き方・写真を誰でも編集。全編集が版として履歴に残り、行単位の差分表示と一手での差し戻しができる |
| **シーンの記述も共同編集** | 場面の説明・話数・画像も誰でも直せる。場所と同じく版の履歴と差し戻しつき |
| **地図から直接書き込む** | 地図をクリック →「ここは○○の第3話のあの場面」を登録。近くの既存の場所を候補に出して重複を防ぐ。既存のピンを押せばその場所が選ばれる |
| **作品は予測入力で選ぶ** | 作品数が増える前提で、プルダウンではなく入力で絞り込む。一覧に無ければその場で作品ごと登録できる |
| **画像を添える** | アニメならその場面の画像、小説なら描写にあたるもの。キャプションと出典も記録 |
| **いいね** | 場所に付けられる。多いほど地図のピンが大きくなり、一覧の上に出る |
| **異説** | まれに場所が割れたときだけ、候補を並べて根拠を書き、投票で確度を出す |

## 主な画面

| パス | 内容 |
| --- | --- |
| `/` | 全国地図、人気の聖地、最近の書き込み |
| `/map` | **地図から書き込む**。種別・作品での絞り込み、都道府県別一覧 |
| `/places` | 場所一覧（いいね順・作品数順・名前順） |
| `/places/[id]` | **場所の項目**。解説・行き方・登場シーン・いいね |
| `/places/[id]/edit` | 項目の編集 |
| `/places/[id]/history` | 編集履歴。版ごとの差分と差し戻し |
| `/scenes/new` | シーンの登録。`?place=` で場所を、`?work=` で作品を固定できる |
| `/passages/[id]/edit` `/passages/[id]/history` | シーンの編集と編集履歴 |
| `/works` `/works/[slug]` | 作品一覧／作品の舞台地図とシーン一覧 |
| `/passages/[id]` | シーンの詳細。異説が出ている場合はここで議論・投票 |
| `/users/[handle]` | 登録したシーン・編集・いいね |
| `/about` | 参加のしかたと決まりごと |

## 確度について

異説が出ていないシーンでは確度を表示しません（「定説」として扱います）。
複数の候補が並んだときだけ、`src/lib/confidence.ts` で得票シェアを計算します。

```
重み w = max(0, 賛成 − 反対) + 0.5
確度   = w ÷ Σw
```

`+0.5` は票が少ないうちに確度が振り切れないようにするラプラス平滑化です。

## 技術構成

- **Next.js 15（App Router）/ React 19 / TypeScript** — 更新は Server Actions
- **SQLite（better-sqlite3）** — `data/seichi.db` に自動生成・自動シード
- **Leaflet + OpenStreetMap** — APIキー不要
- **Tailwind CSS v4**
- 認証は scrypt によるパスワードハッシュ＋DBセッション（Cookie）
- 画像は `data/uploads/` に保存し、`/uploads/[name]` のルートハンドラから配信
  （`public/` は `next start` がビルド時のファイルしか配信しないため使えない）

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
```

初回起動時に `data/seichi.db` が作られ、サンプルデータが投入されます。
作り直したいときは `rm -rf data` してから再起動してください。

```bash
npm run build && npm start   # 本番ビルド
```

### お試し用アカウント

サンプルデータのユーザーは全員パスワード `seichi2024` でログインできます
（例：`kobo_map` / `soseki_walk` / `numazu_p` / `kamakura_lo`）。

## データモデル

```
places（場所＝項目）
  ├ place_revisions（版の履歴）      … 編集のたびに編集後の状態を1件積む
  ├ place_likes（いいね）
  └ identifications（結びつけ）
       ├─ passages（シーン）→ works（作品）   画像・キャプション・出典を持つ
       │    └ passage_revisions（版の履歴）   … シーンも共同編集できる
       ├─ votes（賛成・反対）                 … 異説が出たときだけ効く
       └─ comments（議論）
```

## 収録データについてのおことわり

- **初期データはサンプルです。** 座標・記述・確度のいずれも正確性を保証しません。
  それを利用者の手で直していくこと自体がこのサービスの目的です。
- 収録作品は『こころ』『三四郎』『坊っちゃん』『雪国』『君の名は。』
  『ラブライブ！サンシャイン!!』『SLAM DUNK』。
  『君の名は。』は須賀神社の男坂・飛騨古川駅・飛騨市図書館・落合バス停・
  国立新美術館・四ツ谷駅など9地点を収録しています。
- 本文の逐語引用は**保護期間の終わった作品**（夏目漱石・川端康成）に限っています。
  著作権の生きている作品は「場面の記述」として要約で登録しています。
- 投稿画像は自分で撮影したものを推奨しています。作品の映像・挿絵の転載は
  引用の範囲を超えないようにしてください。
- 実在の場所には、そこで暮らし働いている人がいます。私有地や住宅の特定・公開は
  行わない前提で運用してください。
